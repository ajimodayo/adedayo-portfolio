# Ajimo Adedayo Ebenezer — Portfolio

## Files
- `index.html` — main portfolio page
- `style.css` — styling and responsive layout
- `script.js` — mobile navigation

## Adding project screenshots later
1. Create an `images` folder beside `index.html`.
2. Put your screenshot inside it, e.g. `mock-exam.png`.
3. In `index.html`, replace the project placeholder with:
   `<img src="images/mock-exam.png" alt="Mock examination platform screenshot">`
4. Add this CSS if needed:
   `.project-image img{width:100%;height:100%;object-fit:cover;display:block}`

The layout is responsive for phones, tablets and laptops.
